# Publicar e atualizar o acervo

O site público é `https://jacino3d.github.io/estante-da-ana/`. Cada commit em `main` publica uma versão pelo GitHub Actions; confira se o fluxo **Publish Estante da Ana** terminou com sucesso.

Para marcar um livro como vendido ou alterar uma estimativa, abra `manage-inventory.html` localmente no computador. Busque o livro, atualize o status ou o preço e baixe o `inventory-status.js`. Envie esse arquivo ao repositório GitHub e confirme o commit. A atualização aparece no site após o Pages concluir a publicação. O editor local não publica por conta própria. Ele foi removido do site público enquanto o acesso privado é configurado.

Não remova nem reordene itens antigos de `INVENTORY_RAW`, pois os códigos identificam cada exemplar. Use o editor e o arquivo `inventory-status.js` mais recentes para preservar as atualizações anteriores.

Os valores são estimativas a negociar com Ana. Entrega e PIX são combinados diretamente; não há cálculo real de frete ou cobrança no site. O contato via WhatsApp abre um rascunho para revisão e envio pelo visitante.
